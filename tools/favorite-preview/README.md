# 本命测试：三版独立试稿

基线提交：7abd904。此目录只用于比较网页视觉方向，不会进入 src 或 dist，也没有改写正式 app、排序模型、角色数据或结果图绘制代码。

在仓库根目录运行：

~~~sh
node tools/favorite-preview.mjs 4184
~~~

- 比较入口：http://127.0.0.1:4184/
- A 工具优先：http://127.0.0.1:4184/tool/favorite/
- B 秘封手记：http://127.0.0.1:4184/notebook/favorite/
- C 白玉楼庭院：http://127.0.0.1:4184/courtyard/favorite/
- 原版：http://127.0.0.1:4184/favorite/

三版加载同一份正式模型与素材，服务端只按页面改写展示文字及样式，并为每版将存档键隔离到 hifuu.favorite.v1.preview.{tool|notebook|courtyard}。原版存档键和生成分享链接格式均未改动。不要把此本地预览服务用于公网部署。

A 删除宣传式首屏、重复流程和装饰拼贴；B 由莲子、梅莉与深蓝灰观测记录形成主题；C 用现有白玉楼图片与妖梦、幽幽子形成较短的浅色页头。三个版本都支持作品勾选、独立选角、比较、并列、撤销、续测和结果导出。

C 沿用 src/favorite/CREDITS.md 所记载的已有背景素材；来源记录不等于作者授权，本试稿不增添新素材或改变许可声明。

npm test 包含试稿渲染、隔离存档键、JS/CSS 解析、资源路由与 HTTP 错误处理回归检查。
