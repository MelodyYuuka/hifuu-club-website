# 东方本命角色测试

原生 HTML / CSS / ES modules，无运行时框架、CDN、字体服务或后端依赖。

## 本地与部署

使用 Node.js 22 或更新版本，在仓库根目录执行：

~~~sh
npm ci
npm run dev
# http://127.0.0.1:4173/favorite/
npm test
npm run build
node tools/serve.mjs --dist 4174
~~~

将 dist 发布到任意静态主机即可，通过 /favorite/ 访问。构建会保留素材来源与许可文件，但不发布只用于 Node.js 测试的 favorite/package.json。
所有资源采用相对路径，支持部署于仓库子路径，不需要 SPA 重写规则。
请通过 HTTP 服务运行，不要直接双击 HTML（浏览器会限制 file:// ES modules）。
首页 src/index.html 已添加入口。没有改动 index2.html 或 runner。

## 功能

- 173 位角色，作品更新至《东方锦上京》（TH20，含 EX）；36 个作品 / 分类条目、3 个分类；支持作品名 / 编号搜索、当前分类批量勾选、角色去重、经典 / 秘封预设、全部角色独立勾选与排除。
- 本命 / 前十 / 全排名；左、右、并列选择；键盘快捷键；撤销。
- 惰性锦标赛排序，只提取目标名次；边界并列完整保留，不伪造剩余排名。
- 每次选择保存到本机 localStorage；刷新后主动续测；启动新测试前确认覆盖。
- 完整文字榜单、无服务器的结果链接、PNG 结果图（前 20 条，页面明确提示）。
- 始终显示角色立绘，支持加载失败回退、窄屏适配、减少动态效果、键盘与焦点。

## 数据与扩展

characters.js 是静态角色和作品数据。角色名字、短简介与搜索别名由 YuukaBot-v6 的 THBWiki 档案和别名表生成；短简介不保证是官方称号。新增角色时同时添加立绘及来源声明。
导入仅更新显示资料，保留稳定 ID、角色顺序、作品标签和立绘路径，不自动扩容本站名单。

~~~sh
node tools/import-favorite-characters.mjs --bot-root /path/to/YuukaBot-v6/YuukaBot --check
# 去掉 --check 可重新生成；审查差异后同步本地字体字形子集，再运行测试和构建。
python tools/subset-favorite-fonts.py
~~~

映射保存在 tools/favorite-character-sources.json；3 位缺少独立档案的角色与必要的短文案修订在导入工具中显式维护。资料来源、修订口径与文本许可见 CREDITS.md。
版本 7 仅重建角色显示资料与别名；版本 6 的作品选择、快捷预设、进行中排序和分享结果原样兼容。
model.js 负责筛选、存档校验、分享链接与文本导出；sorter.js 负责排序。

## 按角色挑选

列表始终包含全部 173 位角色，按角色名字 / 短简介 / 别名搜索，不再受上方作品选择限制。
勾选状态反映实际参赛名单：所选作品中的角色默认勾选，范围外角色可以单独添加，不会连带选中整部作品。
settings.included 保存范围外的手工添加，settings.excluded 保存排除；候选人是“作品角色与手工添加的并集，再减去排除”，自动去重。

手动修改作品保留角色添加 / 排除；重新勾选快捷预设、清空范围或恢复默认时，重新生成名单并清除手工调整。
新增的 included 字段可选，旧存档按空数组处理；刷新保留手工选角，不改变已经开始的测试与分享结果。

## 雅致均衡字体

页面使用本站加载的 Noto Serif SC / Noto Sans SC 可变字体子集。`style.css` 声明本地 WOFF2，页面预载两份字体；失败时沿用系统字体回退。字体 OFL 许可和来源记录保存在 `assets/fonts/` 与 CREDITS.md，不依赖外部字体服务。

`typography.js` 统一结果 PNG 的字体族。导出先与图片并行等待常规／半粗两种字重，再测量与绘制；字体失败、API 缺失或 5 秒超时仍可导出，按钮会恢复。

新增页面文字或角色名称后，运行：

```powershell
python tools/subset-favorite-fonts.py
```

需要已有 Python fontTools + Brotli 和两份完整 Noto SC 字体；默认读取 Windows 已安装的 NotoSansSC-VF.ttf / NotoSerifSC-VF.ttf，也可用 `--sans` / `--serif` 指定源文件。普通 `npm run build` 只发布生成好的 WOFF2，不要求 Python 或用户机器安装字体。`npm test` 验证子集 SHA-256 与页面中文／日文字符覆盖，避免改文案后静默回退其他字体。
